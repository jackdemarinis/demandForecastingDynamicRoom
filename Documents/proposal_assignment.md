CSC 561 Individual Project Proposal



Fill in this template for your CSC 562 final project proposal. This one to two page document will summarize your goals and methods. A successful project should be a substantial project, with the most interesting projects suitable for publication. All projects will be written up in publication format (either 4 or 8 pages, with appendix).



Purpose, Motivation, Impact



Describe the purpose of your project. What problem does this solve? What impact might it have? Is there interest from the scientific community, or some human-interest benefit to your project?



Dataset



Describe the data that will be used for this project. Where does it come from? Who collected it and when? Can it answer the project question? Are multiple datasets used? Will you collect data?



Methods



Input Data



Are the input data images, tabular or in another form? How will you preprocess or structure your input so that it can be input into a neural network model? How will you conduct data splitting to have train, validation and test sets; or will you use a cross validation or nested cross validation method?



Target Variable(s)



Is the target variable a class (classification task), a mask (segmentation task) or some other labels?



Model



What is the architecture of the model you will use? ResNet? A transformer? Multiple models for comparison?



Metrics and Results



What graphs and results will you show? AUROC curves, accuracy, F1 scores, comparison tables, architecture diagram, etc. How will you visualize outputs of the model on new data? Will you test on an external dataset to confirm the generalizability of your method?



Overlap statement



Is this project aligned with your thesis research (encouraged)? How? Is this project overlapping with a course project from another class (allowed with approval of both instructors)? How do you address the requirements for both classes?
